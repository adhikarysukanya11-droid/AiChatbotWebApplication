🤖 Nexa AI

Your Smart AI Assistant

Nexa AI is a modern and responsive AI Chatbot Web Application built with
Python and Flask. The project provides a clean chat interface where
users can enter messages and interact with a chatbot-style interface.

This project was developed as a practical web development project to
gain hands-on experience with frontend design, Flask backend
development, JavaScript interactions, and API integration.

⚙️ Installation and Setup

1. Clone the Repository

git clone https://github.com/yourusername/Nexa-AI.git

2. Open the Project Folder

cd Nexa-AI

3. Create a Virtual Environment

python -m venv venv

4. Activate the Virtual Environment

Windows

venv\Scripts\activate

macOS / Linux

source venv/bin/activate

5. Install Dependencies

pip install -r requirements.txt

▶️ Run the Application

Start the Flask development server:

python app.py

The application will be available at:

http://127.0.0.1:5000

To open the chatbot:

http://127.0.0.1:5000/chat
